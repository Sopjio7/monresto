# SopJio AfricanResto

Site vitrine statique en HTML, CSS et JavaScript natif, construit à partir des fichiers du projet fourni.

## Ouvrir le site

Ouvrir `index.html` dans un navigateur. Pour tester depuis un serveur local, lancer depuis ce dossier :

```sh
python3 -m http.server 8000
```

Puis visiter `http://localhost:8000`.

## Fichiers

- `index.html` : accueil, sélection des plats, présentation, avis de démonstration et localisation.
- `plats.html` : carte détaillée et prix.
- `styles.css` : identité visuelle et mise en page responsive.
- `app.js` : menu mobile, commandes du carrousel, détails des plats et animations discrètes.
- `images/` : photographies fournies dans le ZIP d’origine et logo SopJio fourni, intégré sous `images/logo-sopjio.png`.

Aucun framework, paquet ou outil de compilation n’est requis. La carte intégrée et les liens d’itinéraire utilisent Google Maps.
